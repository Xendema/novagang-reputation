# NOVAGANG X ClassicCounter — Reputation list

Публичный список репутации игроков для расширения **NOVAGANG X ClassicCounter**.

## Формат

```json
{
  "updated": "2026-11-14",
  "users": {
    "76561198000000001": {
      "rep": -1,
      "tag": "scam",
      "note": "sent a fake trade offer",
      "by": "XEN",
      "ts": 1731600000000
    }
  }
}
```

| Поле | Обяз. | Что значит |
|---|---|---|
`users` | да | объект, ключ — SteamID64 (17 цифр) |
`rep` | нет | `1` — плюс, `-1` — минус, `0` — нейтрально |
`tag` | нет | короткая метка до 24 символов (`scam`, `trusted`, `slow`) |
`note` | нет | пояснение до 140 символов |
`by` | нет | кто поставил (ник или SteamID64) |
`ts` | нет | время оценки, unix-время в миллисекундах |

Расширение принимает и «голую» карту без обёртки `users`:

```json
{ "76561198000000001": { "rep": -1, "tag": "scam" } }
```

## Как подключить

1. Опубликуйте этот репозиторий (публичный — иначе raw-ссылка потребует токен).
2. Откройте `reputation.json` на GitHub и нажмите **Raw**.
3. Скопируйте адрес — он должен начинаться с `https://raw.githubusercontent.com/`.
4. В расширении: левое меню → **Reputation** → вставьте ссылку → **Save URL**.
5. Список подтянется сразу; дальше он кешируется на час и обновляется в фоне при открытии профиля или страницы уведомлений. Кнопка **Refresh** форсирует обновление.

Через CDN тоже работает (быстрее, но кеш дольше):

```
https://cdn.jsdelivr.net/gh/<user>/<repo>@main/reputation.json
```

## Как пополнять список

**Свой вклад из расширения:** профиль → `+1` / `−1` → меню Reputation → **Export mine** → скачается `reputation.json` → замените им файл в репозитории (или слейте `users` вручную) → commit.

**Чужой вклад:** любой может прислать Pull Request с новой записью. GitHub Actions автоматически проверит структуру (`scripts/validate.js`), вы смотрите diff и мержите.

**Автоматика (по желанию):** workflow уже обновляет статус проверки на каждый push/PR; можно добавить шаг, который сам проставляет `updated` в сегодняшнюю дату.

## Автообновление из расширения

Расширение умеет писать в этот файл само — без ручного редактирования:

1. Создайте fine-grained токен GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
   - Repository access: только этот репозиторий.
   - Permissions → Repository permissions → Contents: **Read and write**.
   - Больше ничего не выдавайте.
2. В расширении: левое меню → Reputation → поля `owner/repo`, путь `reputation.json`, ветка `main`, вставьте токен → **Save GitHub**.
3. Кнопка **Push mine** читает текущий файл, вливает ваши локальные оценки (чужие записи не трогает) и делает коммит.

Токен хранится только в `chrome.storage` на вашей машине и отправляется исключительно на `api.github.com`.
В коде расширения его нет — каждый пользователь подключает свой собственный.

Если файл успели изменить с другой стороны, GitHub вернёт 409: нажмите **Push mine** ещё раз, расширение перечитает `sha` и повторит коммит.

## Правила

- Только SteamID64 из 17 цифр в ключах.
- `rep` — строго `1`, `0` или `-1`.
- Без оскорблений и личных данных: `note` — про сделки, а не про человека.
- Одна запись на игрока: при повторной оценке заменяйте существующую.
- Спорные записи удаляются по решению владельца списка.

## Локальная проверка

```bash
node scripts/validate.js reputation.json
```

Выведет `OK: N записей` или список проблем и код возврата 1.
